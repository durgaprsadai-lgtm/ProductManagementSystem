# ProductManagementSystem

An end-to-end **ASP.NET Core Web API** project demonstrating **advanced design patterns** including:

- Repository Pattern
- Unit of Work Pattern
- CQRS with MediatR
- Entity Framework Core with SQL Server
- Swagger for API documentation

---

## 🚀 Features
- CRUD operations for Products
- Clean architecture with Domain, Infrastructure, and WebAPI layers
- Separation of concerns using Repository + Unit of Work
- CQRS + Mediator for command/query handling
- Swagger UI for easy API testing
